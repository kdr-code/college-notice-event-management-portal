# College Notice & Event Management Portal

A web-based portal for managing college notices, events, registrations, reminders, and administrative reports.

## Modules

- User Login & Registration
- Student Dashboard
- Notice Management
- Event Calendar & Registration
- Reminder & Notification
- Admin Management & Reports

## Technology Stack

- HTML5
- CSS3
- JavaScript
- Node.js / Express
- MySQL
- Git / GitHub

## Project Process

The project follows Agile Scrum with application lifecycle management practices including requirements, task management, development, testing, and version control.
